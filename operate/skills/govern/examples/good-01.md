# Good — 사내 문서 RAG 에이전트 거버넌스 게이트

위험 등급: 내부 문서(일부 기밀) × 읽기+요약 전송 = High → 전 항목 점검

```
dlp:        ⚠️ 사내 위키 읽기는 OK / 요약이 외부 모델 API로 나감 →
            기밀 태그 문서는 인덱스에서 제외(레다크션) 적용
audit:      ✅ query·문서ID·요약·사용자 append-only 로그, 6개월 보존
killswitch: ✅ 인덱스 비활성 플래그(<1분), 롤백=이전 인덱스 스냅샷
permissions:✅ 읽기 전용 토큰, 쓰기 도구 없음, 외부 전송은 요약 텍스트만
orphaned:   ⚠️ 파일럿 종료된 'legal-bot' 동일 인덱스 접근 잔존 발견 → 회수
```

판정: CONDITIONAL GO
조건: (1) 기밀 태그 문서 인덱스 제외 검증 (2) legal-bot 접근 회수 → 둘 다 완료 후 GO

왜 좋은가:
- 위험 등급을 먼저 산정해 점검 깊이를 정함
- 외부로 나가는 데이터(요약)를 정확히 짚고 통제(레다크션)를 붙임
- 문서가 아니라 실행 가능한 킬스위치/롤백 대상을 명시
- orphaned 에이전트를 인벤토리로 발견 → 잠복 리스크 제거
