# Bad — 통제를 배포 후로 미루는 게이트

```
"슬랙 자동응답 에이전트, 데모 잘 됐고 PII는 거의 안 다루니 바로 켜죠.
 로그랑 정지 버튼은 트래픽 보고 나중에 붙입시다."
```

❌ 문제점
- 위험 등급 미산정 — "거의 안 다룬다"는 추측, 실제 DM·고객정보 접근 여부 미확인
- 킬스위치/롤백을 배포 후로 미룸 → 오작동 시 멈출 방법 없음
- 감사 로그 부재 → 누가 무엇을 전송했는지 추적 불가
- 도구 권한 미점검 — 슬랙 쓰기/DM 전송 권한이 최소권한인지 확인 안 함
- "데모 성공 = 배포 가능"으로 통제 가능성을 건너뜀

→ 재작업
1. 위험 등급: 내부 대화(PII 가능) × 외부 전송(메시지 발송) = High
2. dlp(DM·PII 접근 범위) → audit(전송 로그) → killswitch(발송 중단 플래그) 선결
3. 최소권한: 지정 채널만, DM 전송 권한 회수 또는 HITL
4. GO 판정 후 배포
